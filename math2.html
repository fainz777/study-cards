Ⅰ Векторы

Базовые определения: вектор — направленный отрезок, у которого есть длина и направление. Обозначается $\vec{AB}$ (начало A, конец B) или $\mathbf{a}$.

⚡ Операции с векторами

➕ Сложение
правило треугольника $\vec{AB} + \vec{BC} = \vec{AC}$
правило параллелограмма $\vec{a} + \vec{b}$ — диагональ
✅ Важно: конец первого = начало второго.
➖ Вычитание
$\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$
золотое правило $\vec{XY} = \vec{AY} - \vec{AX}$
(из конца вычитаем начало)
📍 Пример: $\vec{DK} = \vec{AK} - \vec{AD}$
✖️ Умножение на число
$k \cdot \vec{a}$
  • $k > 0$ — направление сохраняется
  • $k < 0$ — направление меняется на противоположное
  • длина умножается на $|k|$
📏 Длина (модуль)
$|\vec{AB}| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$
$|\vec{AB}| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$

🎯 Середина отрезка (векторная форма)

Если M — середина AB
$\vec{AM} = \frac{1}{2}\vec{AB}$
$\vec{OM} = \frac{\vec{OA} + \vec{OB}}{2}$ (для любой O)
Частый приём в задачах
Если K — середина BO, то $\vec{BK} = \frac{1}{2}\vec{BO}$
$\vec{AK} = \vec{AB} + \vec{BK}$

▱ Параллелограмм (векторные соотношения)

СвойствоФормула
Диагональ AC$\vec{AC} = \vec{AB} + \vec{AD}$
Диагональ BD$\vec{BD} = \vec{AD} - \vec{AB}$
Центр O (половина диагонали)$\vec{AO} = \frac{1}{2}\vec{AC}$
Сумма диагоналей$\vec{AC} + \vec{BD} = 2\vec{AD}$

📌 Координаты векторов

Координаты $\vec{AB}$
$\vec{AB} = (x_B - x_A;\; y_B - y_A)$
правило из конца вычитаем начало
Операции в координатах
$\vec{a} \pm \vec{b} = (x_a \pm x_b;\; y_a \pm y_b)$
$k\cdot\vec{a} = (k x_a;\; k y_a)$

📋 Популярные выражения (параллелограмм ABCD)

ВекторВыражение через $\vec{AB}$ и $\vec{AD}$
$\vec{AC}$$\vec{AB} + \vec{AD}$
$\vec{BD}$$\vec{AD} - \vec{AB}$
$\vec{AO}$ (O — центр)$\frac{1}{2}(\vec{AB} + \vec{AD})$
$\vec{BO}$ (O — центр)$\frac{1}{2}(\vec{AD} - \vec{AB})$
$\vec{AK}$ (K — середина AO)$\frac{1}{4}\vec{AB} + \frac{1}{4}\vec{AD}$
$\vec{AK}$ (K — середина BO)$\frac{3}{4}\vec{AB} + \frac{1}{4}\vec{AD}$
$\vec{DK}$ (K — середина AO)$\frac{1}{4}\vec{AB} - \frac{3}{4}\vec{AD}$
⚠️ Типичные ошибки:
  • Нельзя писать $\vec{AK} = \vec{AB} + \vec{AO}$ — концы и начала не совпадают (нужно $\vec{AB} + \vec{BK}$).
  • Не путать $\vec{DK}$ и $\vec{KD}$ — это противоположные векторы: $\vec{DK} = -\vec{KD}$.
  • Если K — середина AO, то $\vec{AK} = \frac{1}{2}\vec{AO}$, а не $\vec{AO}$.

Ⅱ Алгебра

📌 Степени
$a^{m/n} = (\sqrt[n]{a})^m$
$a^m \cdot a^n = a^{m+n}$
📌 Логарифмы
$\log_a b^n = n \log_a b$
$\log_a (bc) = \log_a b + \log_a c$
📌 Квадратное уравнение
$ax^2 + bx + c = 0$
$D = b^2 - 4ac$
$x = \frac{-b \pm \sqrt{D}}{2a}$
📌 Свойства модуля
$|a| < b \;\Leftrightarrow\; -b < a < b$
$|a| \ge 0$

Ⅲ Геометрия

📐 Треугольник
Сумма углов: $180^\circ$
Теорема Пифагора: $c^2 = a^2 + b^2$
Формула Герона: $S = \sqrt{p(p-a)(p-b)(p-c)}$
⚪ Окружность / шар
Площадь сферы: $S = 4\pi R^2$
Радиус описанной окружности: $R = \frac{abc}{4S}$
📦 Пирамида
Апофема $l = \sqrt{h^2 + r^2}$
Угол наклона грани: $\cos \alpha = \frac{r}{l}$
📏 Периметр
Прямоугольник: $P = 2(a+b)$

Ⅳ Тригонометрия

Основные тождества
$\sin^2 \alpha + \cos^2 \alpha = 1$
$\sin 2\alpha = 2\sin\alpha\cos\alpha$
$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$
Формулы приведения
$\cos(\frac{\pi}{2} - \alpha) = \sin\alpha$
$\sin(\frac{3\pi}{2} - \alpha) = -\cos\alpha$
$\sin(\pi - \alpha) = \sin\alpha$
