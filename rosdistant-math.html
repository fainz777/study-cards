📘 Математика: от простого к сложному

🧠 Полный справочник с разбором каждой темы и пошаговыми примерами.
Всё по программе ТГУ: пределы, производные, интегралы, матрицы, векторы, геометрия и многое другое.

🧩 1. Функции — основа всего

Функция — это правило, которое каждому значению x (аргумент) ставит в соответствие единственное значение y (функция).

📌 Аналогия: как автомат с кофе: нажали кнопку «капучино» (x) — получили чашку кофе (y).

🔹 Область определения и область значений

  • Область определения (D) — все x, которые можно подставить. Например, у y = √x область определения: x ≥ 0, потому что корень из отрицательного не берём.
  • Область значений (E) — все y, которые получаются. У y = x² область значений: y ≥ 0, потому что квадрат всегда неотрицательный.
📌 Пример: Найти область определения функции y = 1/(x−3).
Шаг 1: Знаменатель не может быть равен нулю, так как на ноль делить нельзя.
Шаг 2: x − 3 ≠ 0 → x ≠ 3.
Ответ: D = (−∞; 3) ∪ (3; +∞) — все числа, кроме 3.

🔹 Чётность и нечётность

  • Чётная: f(−x) = f(x). График симметричен относительно оси Y. Пример: y = x², y = cos x.
  • Нечётная: f(−x) = −f(x). График симметричен относительно начала координат. Пример: y = x³, y = sin x.
📌 Пример: Проверить чётность f(x) = x⁴ − 2x².
Шаг 1: Подставим −x: f(−x) = (−x)⁴ − 2(−x)² = x⁴ − 2x².
Шаг 2: Получили f(−x) = f(x) → функция чётная.

🚀 2. ПРЕДЕЛЫ — ПОДРОБНЫЙ РАЗДЕЛ (самое важное)

🔹 Что такое предел на пальцах?

Предел — это число, к которому функция приближается, когда аргумент становится очень близким к какому-то значению или уходит в бесконечность.

🎯 Аналогия: Вы идёте к двери. Каждый шаг вы приближаетесь, но до двери не доходите. «Дверь» — это и есть предел. Функция может никогда не достигнуть предела, но подходить к нему всё ближе.

lim (x → a) f(x) = A   →   «при x, стремящемся к a, f(x) стремится к A»

🧠 Виды пределов:

  • Предел в точке — когда x → a (например, x → 2).
  • Предел на бесконечности — когда x → ∞ (икс растёт бесконечно) или x → −∞.
  • Односторонние пределы:
    • lim (x → a⁻) — стремимся к a слева (со стороны меньших чисел).
    • lim (x → a⁺) — стремимся к a справа (со стороны больших чисел).
    Если левый и правый пределы равны, то предел существует.

🔹 Как вычислять пределы? (главные приёмы)

📌 Приём 1: Прямая подстановка

Самый простой способ — просто подставить число вместо x.

📌 Пример: Найти lim (x → 2) (x² + 3x − 1).
Решение: Подставляем x = 2: 2² + 3·2 − 1 = 4 + 6 − 1 = 9.
Ответ: 9.

📌 Приём 2: Раскрытие неопределённости «0/0»

Если подстановка даёт 0/0 — это неопределённость. Её нужно раскрыть.

📌 Пример: Найти lim (x → 3) (x² − 9)/(x − 3).
Шаг 1: Подставляем 3: (9−9)/(3−3) = 0/0 — неопределённость.
Шаг 2: Числитель раскладываем по формуле разности квадратов: x² − 9 = (x−3)(x+3).
Шаг 3: Сокращаем (x−3): lim (x → 3) (x+3) = 3+3 = 6.
Ответ: 6.

📌 Приём 3: Домножение на сопряжённое (для корней)

📌 Пример: Найти lim (x → 4) (√x − 2)/(x − 4).
Шаг 1: Подставляем 4: (2−2)/(4−4) = 0/0.
Шаг 2: Домножаем числитель и знаменатель на √x + 2 (сопряжённое):
[(√x − 2)·(√x + 2)] / [(x−4)·(√x + 2)] = (x − 4) / [(x−4)·(√x + 2)].
Шаг 3: Сокращаем (x−4): lim (x → 4) 1/(√x + 2) = 1/(2+2) = 1/4.
Ответ: 1/4.

📌 Приём 4: Пределы на бесконечности (∞/∞)

Если и x, и функция стремятся к бесконечности, делим числитель и знаменатель на старшую степень x.

📌 Пример: Найти lim (x → ∞) (3x² + 2x + 1)/(5x² − 4).
Шаг 1: Старшая степень в числителе и знаменателе — x². Делим всё на x².
(3 + 2/x + 1/x²) / (5 − 4/x²).
Шаг 2: При x → ∞, 1/x → 0, 1/x² → 0.
Ответ: 3/5.

🔹 Два замечательных предела (их нужно знать наизусть)

Первый: lim (x→0) sin x / x = 1
📌 Пример: Найти lim (x→0) sin 5x / x.
Решение: Представим как 5 · (sin 5x)/(5x). При x→0, 5x→0, значит sin 5x / 5x → 1.
Ответ: 5 · 1 = 5.
Второй: lim (x→∞) (1 + 1/x)ˣ = e   (e ≈ 2.71828)
📌 Пример: Найти lim (x→∞) (1 + 2/x)ˣ.
Решение: Сделаем замену t = x/2, тогда x = 2t. При x→∞, t→∞.
lim (t→∞) (1 + 1/t)²ᵗ = [lim (1+1/t)ᵗ]² = e².
Ответ: e².

🔹 Непрерывность функции

Функция непрерывна в точке, если её можно нарисовать, не отрывая ручку от бумаги.

  • Условие непрерывности: lim (x→a) f(x) = f(a).
  • Точки разрыва:
    • I рода — скачок (левый и правый пределы конечны, но не равны). Пример: функция «пол».
    • II рода — бесконечный разрыв (хотя бы один предел равен ∞). Пример: y = 1/x в точке 0.

📈 3. Производная — скорость изменения

🔹 Что такое производная?

Производная показывает, как быстро меняется функция в каждой точке. Это аналог мгновенной скорости в физике.

f'(x) = lim (Δx→0) (f(x+Δx) − f(x)) / Δx

🔹 Геометрический смысл

Производная в точке равна тангенсу угла наклона касательной к графику в этой точке. Если производная большая — касательная крутая.

🔹 Правила дифференцирования

  • Сумма: (u + v)' = u' + v'
  • Произведение: (u·v)' = u'·v + u·v'
  • Частное: (u/v)' = (u'·v − u·v') / v²
  • Сложная функция: f(g(x))' = f'(g)·g'(x)
📌 Пример: Найти производную y = sin(3x²).
Шаг 1: Это сложная функция: внешняя — sin, внутренняя — 3x².
Шаг 2: Производная внешней (sin) — cos, внутренней (3x²) — 6x.
Ответ: y' = cos(3x²) · 6x = 6x·cos(3x²).

🔹 Исследование функций с помощью производной

  • Монотонность: если f'(x) > 0 — функция растёт, если < 0 — убывает.
  • Экстремумы (максимумы и минимумы): в точках, где f'(x) = 0. Если производная меняет знак с + на − → максимум, с − на + → минимум.
  • Выпуклость: f''(x) > 0 — выпуклость вниз («улыбка»), < 0 — вверх («грусть»).

🧮 4. Интегралы — площадь под кривой

🔹 Неопределённый интеграл (первообразная)

Первообразная — это функция, производная которой равна исходной. Неопределённый интеграл — это множество всех первообразных.

∫ f(x) dx = F(x) + C

🔹 Методы интегрирования

  • Непосредственное: прямо по таблице.
  • Замена переменной: вводим новую переменную, чтобы упростить интеграл.
  • Интегрирование по частям: ∫ u dv = u·v − ∫ v du. Используется, когда есть произведение разных типов функций.
📌 Пример (замена): ∫ 2x·eˣ² dx.
Шаг 1: Замена t = x² → dt = 2x dx.
Шаг 2: Получаем ∫ eᵗ dt = eᵗ + C.
Ответ: eˣ² + C.

🔹 Определённый интеграл (площадь)

Определённый интеграл даёт число — площадь фигуры под графиком на отрезке [a, b].

∫ₐᵇ f(x) dx = F(b) − F(a)   (формула Ньютона-Лейбница)
📌 Пример: Найти площадь под y = x² на отрезке [0, 2].
Шаг 1: Первообразная F(x) = x³/3.
Шаг 2: ∫₀² x² dx = F(2) − F(0) = 8/3 − 0 = 8/3.
Ответ: площадь = 8/3 ≈ 2.67.

🧊 5. Линейная алгебра (матрицы и системы)

🔹 Матрицы — это таблицы чисел

  • Сложение: только матрицы одинакового размера, поэлементно.
  • Умножение на число: каждый элемент умножаем на это число.
  • Умножение матриц: A·B возможно, если число столбцов A = числу строк B. Элемент cᵢⱼ — сумма произведений i-й строки A на j-й столбец B.

🔹 Определитель (детерминант)

Это число для квадратной матрицы.

  • Для 2×2: |a b; c d| = a·d − b·c.
  • Для 3×3: вычисляется по правилу треугольников или разложением по строке/столбцу.
📌 Пример: |2 3; 4 5| = 2·5 − 3·4 = 10 − 12 = −2.

🔹 Системы линейных уравнений (СЛАУ)

  • Метод Крамера: использует определители. Работает, если det(A) ≠ 0.
  • Метод Гаусса: универсальный — приводим матрицу к треугольному виду.
  • Метод обратной матрицы: X = A⁻¹·B.

➡️ 6. Векторы — стрелочки в пространстве

🔹 Действия с векторами

  • Сложение: правило треугольника или параллелограмма.
  • Умножение на число: меняется длина, направление может стать противоположным.
  • Скалярное произведение: a·b = |a|·|b|·cos α = x₁x₂ + y₁y₂ + z₁z₂. Если =0 → векторы перпендикулярны.
  • Векторное произведение: результат — вектор, перпендикулярный двум исходным. Его длина = площадь параллелограмма.
  • Смешанное произведение: a·(b×c) — объём параллелепипеда. Объём пирамиды = |a·(b×c)| / 6.

📐 7. Аналитическая геометрия (прямые)

🔹 Уравнение прямой

Основной вид: y = kx + b, где k — угловой коэффициент (tg угла наклона).

  • Параллельны: k₁ = k₂.
  • Перпендикулярны: k₁·k₂ = −1.
Расстояние от точки (x₀, y₀) до прямой Ax + By + C = 0:
d = |Ax₀ + By₀ + C| / √(A² + B²)

🧪 8. Комплексные числа

🔹 Что это?

i — мнимая единица, i² = −1. Комплексное число: z = a + bi.

  • Сложение/вычитание: отдельно a и b.
  • Умножение: как многочлены, i² = −1.
  • Тригонометрическая форма: z = r(cos φ + i sin φ), где r = √(a²+b²).
  • Формула Муавра: zⁿ = rⁿ(cos nφ + i sin nφ).

🎲 9. Теория вероятностей и комбинаторика

🔹 Вероятность

Классическая вероятность: P(A) = m/n, где m — благоприятные исходы, n — все исходы.

🔹 Комбинаторика

  • Факториал: n! = 1·2·...·n.
  • Перестановки: Pₙ = n!.
  • Размещения: Aₙᵏ = n!/(n−k)!.
  • Сочетания: Cₙᵏ = n!/(k!·(n−k)!).
