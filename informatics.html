🔢 1. Системы счисления

📌 Теория

Система счисления — способ записи чисел с помощью цифр. Основание (q) — количество цифр в алфавите.

  • Двоичная (2): 0, 1
  • Троичная (3): 0, 1, 2
  • Четверичная (4): 0, 1, 2, 3
  • Пятеричная (5): 0–4
  • Семеричная (7): 0–6
  • Восьмеричная (8): 0–7
  • Десятичная (10): 0–9
  • Шестнадцатеричная (16): 0–9, A(10), B(11), C(12), D(13), E(14), F(15)

Перевод в десятичную

an-1...a1a0(q) = Σ ai · qi

Пример: 20324 = 2·4³ + 0·4² + 3·4¹ + 2·4⁰ = 128 + 0 + 12 + 2 = 14210

Быстрый перевод через двоичную

  • 8 ↔ 2: каждая 8-ричная цифра → 3 бита (триада)
  • 16 ↔ 2: каждая 16-ричная цифра → 4 бита (тетрада)
Таблица триад (8 ↔ 2)
8-рич.01234567
2-ич.000001010011100101110111
Таблица тетрад (16 ↔ 2)
16-рич.0123456789ABCDEF
2-ич.0000000100100011010001010110011110001001101010111100110111101111

Перевод из десятичной в q-ичную

Последовательно делим число на q, записывая остатки в обратном порядке.

Пример: 2210 → 22/2=11 (0), 11/2=5 (1), 5/2=2 (1), 2/2=1 (0), 1/2=0 (1) → 101102.

Количество чисел в интервале

Для строгого неравенства A < N < B: B – A – 1 чисел.

Если левая граница включена (≤): B – A (при строгой правой).

Если обе границы включены: B – A + 1.

Арифметика в системах счисления

  • Сложение: поразрядно, с переносом, когда сумма ≥ основания.
  • Вычитание: с заёмом из старшего разряда (вес заёма = основание).
  • Умножение/деление: аналогично десятичной системе.
Важно: при работе с 8-ричной системой десяток = 8, в 16-ричной — 16.

Задача 5 (Вариант 6, вопрос 4) — ПОДРОБНОЕ РЕШЕНИЕ

Условие: Значение выражения
3·729⁴ + 2·243⁵ – 4·81⁶ + 27⁷ – 2·9⁸ – 6561
записали в системе счисления с основанием 27. Сколько цифр в этой записи имеют значение больше 13?

▶ Шаг 1. Приводим все слагаемые к виду a·27k

  • 3·729⁴ = 3·(27²)⁴ = 3·27⁸
  • 2·243⁵ = 2·(9·27)⁵ = 2·9⁵·27⁵ = 2·3¹⁰·27⁵ = 2·3·(3³)³·27⁵ = 6·27⁸
  • –4·81⁶ = –4·(3·27)⁶ = –4·3⁶·27⁶ = –4·(3³)²·27⁶ = –4·27⁸
  • +27⁷ = 1·27⁷
  • –2·9⁸ = –2·3¹⁶ = –2·3·(3³)⁵ = –6·27⁵
  • –6561 = –9·27·27 = –9·27²

Собираем коэффициенты: 5·27⁸ + 1·27⁷ – 6·27⁵ – 9·27²

▶ Шаг 2. Записываем в виде таблицы разрядов

В 27-ричной системе разряд k — это 27k. Старший разряд — 8-й (27⁸).

Разряд (27k)876543210
Начальное значение510−600−900

Отрицательные цифры — это сигнал, что нужно сделать заём из старших разрядов.

▶ Шаг 3. Выполняем вычитание (заём из старших разрядов)

В 27-ричной системе заём 1 из соседнего старшего разряда = +27 к текущему.

3а. Исправляем разряд 5 (27⁵): там стоит −6.

  • В разряде 6 (27⁶) — 0, в разряде 7 — 1.
  • Занимаем 1 из разряда 7 → там становится 0.
  • Эта единица превращается в 27 в разряде 6.
  • Из разряда 6 забираем 1 (остаётся 26) и отдаём 27 в разряд 5.
  • В разряде 5: 27 − 6 = 21.
Разряд876543210
После шага 3а50262100−900

3б. Исправляем разряд 2 (27²): там стоит −9.

  • В разрядах 3 и 4 — нули. Занимаем из разряда 5 (там 21).
  • Из разряда 5 забираем 1 → остаётся 20.
  • Эта единица → 27 в разряд 4.
  • Из разряда 4 забираем 1 → остаётся 26, отдаём 27 в разряд 3.
  • Из разряда 3 забираем 1 → остаётся 26, отдаём 27 в разряд 2.
  • В разряде 2: 27 − 9 = 18.

▶ Шаг 4. Итоговая 27-ричная запись числа

Разряд876543210
Итог50262026261800

Число в 27-ричной системе: 5 0 26 20 26 26 18 0 027

▶ Шаг 5. Считаем цифры, которые больше 13

Цифры в записи: 5, 0, 26, 20, 26, 26, 18, 0, 0

Цифры > 13: 26, 20, 26, 26, 18 → ровно 5 штук.

Ответ: 5

🧠 2. Логика и алгоритмы

📌 Теория

Логические операции

  • Отрицание (¬): меняет 0↔1
  • Конъюнкция (∧, И, &): 1 только если оба 1
  • Дизъюнкция (∨, ИЛИ, |): 0 только если оба 0
  • Импликация (→): ложна только при 1→0 (A→B = ¬A ∨ B)
  • Эквивалентность (≡, ~): истина при одинаковых значениях
AB¬AA∧BA∨BA→B
001001
011011
100010
110111

Законы алгебры логики

Законы де Моргана:
¬(A ∨ B) = ¬A ∧ ¬B
¬(A ∧ B) = ¬A ∨ ¬B

Импликация: A → B = ¬A ∨ B
Дистрибутивность: (A ∨ B) ∧ C = (A ∧ C) ∨ (B ∧ C)

Круги Эйлера (для поисковых запросов)

Для решения задач с поисковыми запросами используется формула включений-исключений:

|A ∪ B| = |A| + |B| − |A ∩ B|
|A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

Важно:

  • «И» (&) — это пересечение множеств (∩)
  • «ИЛИ» (|) — это объединение множеств (∪)
Совет: Всегда рисуйте круги Эйлера для наглядности. Обозначьте неизвестное пересечение трёх множеств как x и выражайте через него все остальные области.

Задача 1 (Вариант 1, вопрос 7)

Условие: Для какого наибольшего A выражение (2x+y≠78) ∨ (x<y) ∨ (A<x) тождественно истинно?

Решение: Первые два условия ложны только на прямой y = 78 – 2x справа от y=x. Находим точку пересечения: x = 78 – 2x → 3x = 78 → x = 26. Значит A должно быть 25.

Ответ: 25

Задача 2 (СПО, задача 3) — ПОДРОБНОЕ РЕШЕНИЕ

Условие: Даны запросы:

ЗапросНайдено страниц (сотни тысяч)
Синицы & Воробьи420
Голуби & Воробьи560
Воробьи & (Голуби | Синицы)670

Найти: Голуби & Синицы & Воробьи

▶ Шаг 1. Обозначим множества

  • С — Синицы
  • Г — Голуби
  • В — Воробьи

Нам нужно найти |С ∩ Г ∩ В| — пересечение всех трёх множеств.

▶ Шаг 2. Запишем данные в виде формул

  • |С ∩ В| = 420 (Синицы И Воробьи)
  • |Г ∩ В| = 560 (Голуби И Воробьи)
  • |В ∩ (Г ∪ С)| = 670 (Воробьи И (Голуби ИЛИ Синицы))

▶ Шаг 3. Раскрываем третье выражение

В ∩ (Г ∪ С) = (В ∩ Г) ∪ (В ∩ С) — это объединение двух множеств.

По формуле включений-исключений для двух множеств:

|(В ∩ Г) ∪ (В ∩ С)| = |В ∩ Г| + |В ∩ С| − |(В ∩ Г) ∩ (В ∩ С)|

(В ∩ Г) ∩ (В ∩ С) = В ∩ Г ∩ С — это пересечение всех трёх (то, что нам нужно найти).

Обозначим искомое x = |В ∩ Г ∩ С|

▶ Шаг 4. Подставляем числа

670 = 560 + 420 − x

670 = 980 − x

x = 980 − 670 = 310

▶ Ответ

Ответ: 310

📨 3. Кодирование информации

📌 Теория

Кодирование звука

Основные параметры оцифровки звука:

  • Частота дискретизации (f) — количество измерений уровня сигнала за 1 секунду. Измеряется в Гц.
  • Разрешение (битность) (b) — количество бит для хранения одного измерения.
  • Количество каналов: моно (1) или стерео (2).
Размер файла (бит) = частота_дискретизации × разрешение × количество_каналов × время

В Мбайтах: V (Мбайт) = (f × b × channels × t) / (8 × 1024 × 1024)

Важно: при изменении параметров новый размер считается пропорционально:

Vновый = Vстарый × (channelsновый / channelsстарый) × (bновый / bстарый) × (fновый / fстарый)

Передача данных с архивацией

Скорость передачи: v (бит/с) — количество бит, передаваемых за 1 секунду.

Время передачи: t = V / v, где V — объём данных в битах.

При архивации:

  • Объём сжатого файла = исходный объём × % сжатия / 100
  • Общее время = время_сжатия + время_передачи_архива + время_распаковки
  • Без архивации: время = время_передачи_исходного_файла
Важно: скорость дана в бит/с, а объём в Мбайтах → нужно перевести в биты: 1 Мбайт = 1024×1024×8 бит.

IP-адресация и маски

IP-адрес — 32-битное число (4 байта), записывается как 4 десятичных числа через точку.

Маска сети — определяет, какая часть IP-адреса относится к сети, а какая — к узлу.

  • Единицы в маске (255) — часть адреса сети.
  • Нули в маске (0) — часть адреса узла.
  • Значение 224 = 111000002 — первые 3 бита относятся к сети, остальные 5 — к узлу.
Адрес_сети = IP-адрес & Маска (поразрядная конъюнкция)

Поразрядная конъюнкция (И):

  • 1 & 1 = 1
  • 1 & 0 = 0
  • 0 & 1 = 0
  • 0 & 0 = 0

Пример: 195 & 224 → 195 = 110000112, 224 = 111000002 → 110000002 = 192

Задача 2 (СПО, задача 8) — Передача данных

Условие: Документ 40 Мбайт. Скорость 225 бит/с = 33 554 432 бит/с ≈ 4 Мбайт/с. Сжатый = 30% = 12 Мбайт. Сжатие 3с, распаковка 1с.

Решение:

  • Скорость в Мбайт/с: 225 / 8 / 1024 / 1024 = 4 Мбайт/с
  • Время_А (с архивацией) = 3 + 12/4 + 1 = 3 + 3 + 1 = 7 с
  • Время_Б (без архивации) = 40/4 = 10 с
  • Разница: 10 − 7 = 3 с. Способ А быстрее.

Ответ: А3

⚙️ 4. Теория алгоритмов

📌 Теория

  • Исполнители: Калькулятор (прибавь, умножь), Редактор (замена), Черепашка (графика), Чертёжник (смещение).
  • Рекурсия: функция вызывает саму себя. Для вычисления значения используем подстановку или таблицу значений.
  • Алгоритмы с двоичной записью: дописывание битов по чётности, удаление последнего разряда и т.п. Решаются с конца.
  • Комбинаторика программ: число программ = число перестановок команд с учётом сочетаний: C(n, k) = n! / (k!·(n−k)!).

💻 5. Программирование

📌 Теория

  • Трассировка — выполнение программы по шагам с фиксацией значений переменных.
  • Поиск минимума/максимума в массиве или на интервале.
  • Сумма цифр числа: n = n + s % 10; s = s // 10.
  • Работа с массивами: ввод, поиск пар, перестановки, проверка упорядоченности.
  • Вложенные циклы: для перебора всех пар элементов массива.
