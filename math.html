1️⃣ Определения в прямоугольном треугольнике Геометрия

📌 Для острого угла α в прямоугольном треугольнике:
Синус (sin) — отношение противолежащего катета к гипотенузе.
Косинус (cos) — отношение прилежащего катета к гипотенузе.
Тангенс (tg) — отношение противолежащего катета к прилежащему.
Котангенс (ctg) — отношение прилежащего катета к противолежащему.

📌 Три главные формулы (их нужно знать наизусть!):
sin α = противолежащий / гипотенуза
cos α = прилежащий / гипотенуза
tg α = противолежащий / прилежащий

2️⃣ Определения на единичной окружности Алгебра

📌 На единичной окружности:
Косинус (cos) — это горизонтальная координата точки на окружности.
Синус (sin) — это вертикальная координата точки на окружности.
Тангенс (tg) — это отношение sin к cos (длина касательной к окружности).
Котангенс (ctg) — это отношение cos к sin.

3️⃣ Единичная окружность Анимация

🧭 Точка на круге

Cos (X) Sin (Y) Tg
Угол: 0°  |  cos 1.00   sin 0.00

📌 Тангенс и Котангенс

Тангенс (tg) — это отношение синуса к косинусу. На окружности это длина касательной (зелёная линия) от точки до оси X.

Котангенс (ctg) — это обратное отношение (косинус / синус). Это длина касательной к оси Y.

tg α = sin α / cos α   |   ctg α = cos α / sin α

4️⃣ Графики волн Sin / Cos / Tg

—— Синус —— Косинус —— Тангенс

5️⃣ Основные формулы Шпаргалка

sin² α + cos² α = 1 Основное тригонометрическое тождество
tg α = sin α / cos α    ctg α = cos α / sin α Определение тангенса и котангенса
sin(2α) = 2·sin α·cos α Синус двойного угла
cos(2α) = cos²α − sin²α Косинус двойного угла
sin(α ± β) = sinα·cosβ ± cosα·sinβ Синус суммы / разности
cos(α ± β) = cosα·cosβ ∓ sinα·sinβ Косинус суммы / разности

6️⃣ Значения для базовых углов Наизусть

Угол (α) 0° 30° 45° 60° 90° 180° 270° 360°
sin α 0 ½ √2/2 √3/2 1 0 −1 0
cos α 1 √3/2 √2/2 ½ 0 −1 0 1
tg α 0 √3/3 1 √3 ∞ 0 ∞ 0
ctg α ∞ √3 1 √3/3 0 ∞ 0 ∞

∞ (бесконечность) означает, что функция не определена (деление на ноль).

7️⃣ Обратные тригонометрические функции Арк-функции

📌 Что это?
Арксинус, арккосинус, арктангенс, арккотангенс — это обратные тригонометрические функции.
Если синус превращает угол в число (sin 30° = 0.5), то арксинус превращает число в угол (arcsin 0.5 = 30°).

arcsin x = α
если sin α = x Область определения: x ∈ [−1; 1]
arccos x = α
если cos α = x Область определения: x ∈ [−1; 1]
arctg x = α
если tg α = x Область определения: x ∈ (−∞; +∞)
arcctg x = α
если ctg α = x Область определения: x ∈ (−∞; +∞)
arcsin x + arccos x = 90° Связь между арксинусом и арккосинусом
arctg x + arcctg x = 90° Связь между арктангенсом и арккотангенсом

⚠️ Важно: Арксинус и арккосинус существуют только для чисел от −1 до 1. Например, arcsin 2 — ошибка, такого угла нет. Арктангенс и арккотангенс существуют для любых чисел.

🧩 Пример 1: формула двойного угла

Найдите: 30 · sin 79° · cos 79° / sin 158°

Решение: Замечаем, что 158° = 2 · 79°.
Используем формулу sin 2α = 2 sin α cos α.
Числитель: 30 · sin79°·cos79° = 15 · (2 sin79°·cos79°) = 15 · sin158°.
Дробь: (15 · sin158°) / sin158° = 15.

✅ Лайфхак: Если в задаче угол, которого нет в таблице — ищите формулу двойного угла или приведения!

🧩 Пример 2: прямоугольный треугольник Самый важный

В треугольнике ABC угол A = 90°, tg B = √3, AC = 8. Найдите BC.

📐 Рисунок:

B |\ | \ | \ BC — ? | \ | \ A-----C 8
∠A = 90°  |  AC = 8  |  ∠B — острый

Пошаговое решение:

Шаг 1. Находим угол B через арктангенс.
Дано: tg B = √3.
Вспоминаем таблицу: tg 60° = √3.
Значит: B = arctg(√3) = 60°
Шаг 2. Используем формулу катета через синус.
Правило: «Катет равен произведению гипотенузы на синус противолежащего угла».
В треугольнике: катет AC лежит напротив угла B.
Значит: AC = BC · sin B
Шаг 3. Подставляем числа.
AC = 8, B = 60°, sin 60° = √3/2.
8 = BC · √3/2
Шаг 4. Выражаем BC.
BC = 8 · 2 / √3 = 16/√3 ≈ 9.24

✅ Ответ: BC ≈ 9.24

💡 Важно! Эту задачу можно решить и через тангенс + теорему Пифагора.
Но способ через арктангенс и синус — короче и не требует дополнительных вычислений.

🧩 Пример 3: с арксинусом

Найдите: arcsin(√3/2) + arccos(1/2)

Решение:
arcsin(√3/2) = 60° (потому что sin 60° = √3/2).
arccos(1/2) = 60° (потому что cos 60° = 1/2).
Сумма: 60° + 60° = 120°.

9️⃣ Алгоритм решения задач с треугольником Пошагово

1. Нарисуйте прямоугольный треугольник, отметьте прямой угол.
2. Обозначьте все известные стороны и углы.
3. Выберите нужную тригонометрическую функцию:
  • Если известны противолежащий катет и гипотенуза → sin
  • Если известны прилежащий катет и гипотенуза → cos
  • Если известны оба катета → tg или ctg
4. Запишите формулу и подставьте числа.
5. Если нужно найти угол — используйте арк-функцию (arcsin, arccos, arctg).
6. Если нужно найти гипотенузу — используйте теорему Пифагора.

🧩 Пример 4: формулы приведения

Найдите: 8cos(2π + β) + 10sin(π/2 + β), если cos β = −1/9

Решение:
Шаг 1. Упрощаем первое слагаемое:
cos(2π + β) = cos β (периодичность, период 2π)
→ 8cos(2π + β) = 8cos β

Шаг 2. Упрощаем второе слагаемое:
sin(π/2 + β) = cos β (формула приведения)
→ 10sin(π/2 + β) = 10cos β

Шаг 3. Складываем:
8cos β + 10cos β = 18cos β

Шаг 4. Подставляем cos β = −1/9:
18 · (−1/9) = −2

📌 Использованные формулы:
• Периодичность: cos(2π + α) = cos α
• Приведение: sin(π/2 + α) = cos α
