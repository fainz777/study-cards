📌 Задача №1 — Векторное выражение в параллелограмме
Условие: В параллелограмме ABCD точка O — пересечение диагоналей, точка K — середина отрезка AO. Выразите вектор DK через AB и AD.
Шаг 1. Диагональ AC = AB + AD = a + d
(правило параллелограмма для диагонали)
Шаг 2. Точка O — середина AC, значит
AO = ½ · AC = ½ (a + d) (диагонали точкой пересечения делятся пополам)
Шаг 3. K — середина AO (по условию), поэтому
AK = ½ · AO = ½ · [½ (a + d)] = ¼ (a + d)
фиксировано K — именно середина AO, это задаёт единственное положение.
Шаг 4. Вектор DK = AK − AD
DK = ¼(a + d) − d = ¼a + ¼d − d = ¼a − ¾d (правило вычитания векторов)
✅ Ответ: DK = ¼·AB − ¾·AD (вариант №2)
DK = ¼·AB − ¾·AD
🧠 Математический аппарат (задача №1)
  • Правило параллелограмма: диагональ AC = AB + AD.
  • Свойство середины: если M — середина XY, то XM = ½ · XY.
  • Вычитание векторов: DK = AK − AD.
  • Линейность: ¼(a + d) − d = ¼a − ¾d.

📌 Задача №2 — Равнобедренный треугольник и высота
Условие: В треугольнике ABC угол A равен углу C, а высота AD делит сторону BC пополам. BD = 7,8 см. Найти AC.
Шаг 1. Угол A = углу C → треугольник равнобедренный с основанием AC. Значит, стороны, лежащие напротив равных углов, равны: AB = BC
Шаг 2. Высота AD делит BC пополам → D — середина BC. Значит, BD = DC = 7,8 см Тогда BC = BD + DC = 7,8 + 7,8 = 15,6 см
Шаг 3. Из шага 1: AB = BC = 15,6 см
Шаг 4. В треугольнике ABD (он прямоугольный, так как AD — высота): AB² = AD² + BD² 15,6² = AD² + 7,8² 243,36 = AD² + 60,84 AD² = 182,52
Шаг 5. В треугольнике ADC (тоже прямоугольный): AC² = AD² + DC² AC² = 182,52 + 60,84 = 243,36 AC = √243,36 = 15,6 см
✅ Ответ: AC = 15,6 см (вариант №4)
🧠 Важное наблюдение: Мы получили AB = BC = AC = 15,6 см → треугольник равносторонний. В равностороннем треугольнике все углы по 60°, значит угол A = углу C = 60° — условие выполняется. Поэтому ответ 15,6 см — единственно верный.
AC = 15,6 см
🧠 Математический аппарат (задача №2)
  • Признак равнобедренного треугольника: если два угла равны, то треугольник равнобедренный, и стороны напротив равных углов равны.
  • Свойство высоты: в данном случае высота является медианой (делит сторону пополам).
  • Теорема Пифагора: в прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов.

📌 Задача №4 — Логарифмическое выражение
Условие: Найдите log₅ b, если log₅ b³ = 9.
Решение:

1. Используем свойство логарифма степени:

log₅ b³ = 3 · log₅ b

2. Подставляем данное значение:

3 · log₅ b = 9

3. Делим обе части на 3:

log₅ b = 3

Ответ: 3 (вариант №1)
🧠 Понятийный аппарат
  • Логарифм степени: logₐ bⁿ = n · logₐ b — позволяет выносить показатель степени вперёд как множитель.
  • Решение простейшего логарифмического уравнения: если logₐ x = c, то x = aᶜ.
  • Внимание: в задаче просят найти log₅ b, а не b. Поэтому после нахождения log₅ b = 3 мы сразу получаем ответ.

📌 Задача №6 — Тригонометрическое выражение
Условие: Значение выражения cos²(π/2 − α) + sin²(3π/2 − α) − sin²α равно
Решение:

1. Упрощаем первое слагаемое по формуле приведения:

cos(π/2 − α) = sinα

Значит: cos²(π/2 − α) = sin²α.

2. Упрощаем второе слагаемое по формуле приведения:

sin(3π/2 − α) = −cosα

Значит: sin²(3π/2 − α) = cos²α.

3. Подставляем в исходное выражение:

sin²α + cos²α − sin²α

4. Сокращаем: sin²α − sin²α = 0, остаётся cos²α.

Ответ: cos²α
🧠 Понятийный аппарат
  • Формулы приведения: позволяют упрощать тригонометрические выражения с углами π/2 ± α, π ± α, 3π/2 ± α.
  • Использованные формулы:
    • cos(π/2 − α) = sinα
    • sin(3π/2 − α) = −cosα
  • Основное тригонометрическое тождество: sin²α + cos²α = 1.
📌 Задача №6 — Угол между радиусами вписанной окружности
Условие: Известно, что △ABC равнобедренный, AB = BC, ∠B = 76°, точка O является центром вписанной окружности, OD и OE — радиусы этой окружности (D ∈ AB, E ∈ AC). Тогда ∠DOE равен
Шаг 1.

Треугольник ABC равнобедренный с основанием AC (так как AB = BC).

Углы при основании равны:

∠A = ∠C = (180° − 76°) / 2 = 104° / 2 = 52°

Шаг 2.

D ∈ AB — точка касания вписанной окружности со стороной AB.

E ∈ AC — точка касания вписанной окружности со стороной AC.

Радиусы OD и OE проведены в точки касания, значит они перпендикулярны соответствующим сторонам:

OD ⟂ AB, OE ⟂ AC

Шаг 3.

Угол между двумя прямыми равен углу между их перпендикулярами (или смежному с ним).

Угол между AB и AC — это угол при вершине A:

∠BAC = 52°

Угол между перпендикулярами к сторонам AB и AC равен:

∠DOE = 180° − ∠BAC = 180° − 52° = 128°

✅ Ответ: 128° (вариант №3)
∠DOE = 128°
🧠 Понятийный аппарат
  • Вписанная окружность — окружность, касающаяся всех сторон треугольника.
  • Радиус, проведённый в точку касания, перпендикулярен стороне треугольника.
  • Угол между двумя перпендикулярами к сторонам угла равен либо самому углу, либо дополняет его до 180°.
  • Сумма углов треугольника равна 180°.
  • В равнобедренном треугольнике углы при основании равны.

📌 Задача №8 — Площадь поверхности шара
Условие: На поверхности шара даны точки C, D, E: CD=7, DE=8, CE=9. Расстояние от центра шара до плоскости треугольника = 1. Найдите площадь поверхности шара.
Решение: 1. По формуле Герона находим площадь треугольника CDE:
p = (7+8+9)/2 = 12.
S = √(12·5·4·3) = √720 = 12√5.
2. Радиус описанной окружности треугольника:
R₀ = abc/(4S) = 7·8·9/(4·12√5) = 504/(48√5) = 10,5/√5.

📌 Задача №9 — Задача на смеси (растворы)

Ответ: 100
🧠 Понятийный аппарат
  • Процентная концентрация: массовая доля вещества в растворе, выраженная в процентах.
  • Масса соли в растворе: m = (концентрация/100) · масса раствора.
  • Система уравнений: используется для нахождения двух неизвестных величин.
📌 Задача №10 — Высказывания о числах
Условие: Какие высказывания о числах не являются верными?
Решение: Проверяем каждое утверждение:
1. «Любое действительное число является либо положительным, либо отрицательным» — неверно, так как 0 не относится ни к тем, ни к другим.
2. «Любое действительное число является рациональным» — неверно, например √2 — иррациональное.
3. «Любое иррациональное число является действительным» — верно (все иррациональные — действительные).
4. «Любое рациональное число является либо целым, либо дробным» — верно (определение рационального числа).
Ответ: 1 и 2
🧠 Понятийный аппарат
  • Действительные числа: объединяют рациональные и иррациональные числа.
  • Рациональные числа: числа, которые можно представить в виде m/n, где m и n — целые числа, n ≠ 0.
  • Иррациональные числа: числа, которые нельзя представить в виде обыкновенной дроби (например, √2, π).
  • Ноль: не является ни положительным, ни отрицательным.

📌 Задача №23 — Неравенство с дробью
Условие: Число целых решений неравенства (x²−10x+25)/((x−5)(x−7)) ≥ −1 на промежутке [4; 9]
Решение: 1. x²−10x+25 = (x−5)².
2. Сокращаем (при x ≠ 5): (x−5)²/((x−5)(x−7)) = (x−5)/(x−7).
3. Неравенство: (x−5)/(x−7) ≥ −1.
4. (x−5)/(x−7) + 1 ≥ 0 → (2x−12)/(x−7) ≥ 0 → 2(x−6)/(x−7) ≥ 0.
5. Метод интервалов: x ∈ (−∞; 6] ∪ (7; ∞).
6. На промежутке [4; 9] целые числа: 4, 5, 6, 8, 9 → 5 чисел.
Ответ: 5
🧠 Понятийный аппарат
  • Сокращение дроби: (x−5)²/((x−5)(x−7)) = (x−5)/(x−7) при x ≠ 5.
  • Метод интервалов: находим нули числителя и знаменателя, отмечаем на прямой, определяем знаки.
  • Учёт ОДЗ: знаменатель не должен обращаться в ноль (x ≠ 7).
